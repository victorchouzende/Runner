# 🏃‍♂️ Metropolis Runner — Jogo 2D Platformer & Endless Runner

Um jogo 2D de corrida infinita (*Endless Runner*) e plataforma desenvolvido com HTML5 Canvas, CSS3 e JavaScript puro, contando com física de pulo, animações em pixel art, efeito parallax e temática urbana futurista.

---

## 📌 Sobre o Projeto

O **Metropolis Runner** combina a dinâmica clássica dos jogos de plataforma 2D com a intensidade dos *endless runners*. O jogador controla um personagem que avança por uma metrópole caótica, precisando saltar sobre plataformas metálicas e desviar de obstáculos com precisão enquanto a velocidade do jogo aumenta progressivamente.

---

## ✨ Funcionalidades e Diferenciais

- 🕹️ **Física e Mecânicas de Pulo:** Gravidade, física de salto, detecção precisa de colisões (AABB) e plataformas móveis/fixas.
- 🏙️ **Cenário Dinâmico em Parallax:** Fundo de metrópole futurista com múltiplas camadas em rolamento infinito para sensação de velocidade e profundidade.
- 🎨 **Animações em Pixel Art:** Personagem e elementos gráficos integrados via *sprite sheets* para movimentação fluida.
- ⚡ **Dificuldade Progressiva:** Aceleração gradual do ritmo do jogo e variação no surgimento de obstáculos conforme a pontuação sobe.
- 🏆 **Pontuação & Game Over:** Contagem de pontos em tempo real, sistema de *high score* e tela de reinício rápido.
- 📱 **Controles Multidiscipinares:** Suporte para teclado (Barra de Espaço / Setas) e tela sensível ao toque para dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem & Canvas:** JavaScript (ES6+ / HTML5 Canvas API)
- **Estrutura & Estilização:** HTML5, CSS3 (Keyframes, Flexbox)
- **Design & Assets:** Pixel Art, Sprite Sheets, Parallax Background
